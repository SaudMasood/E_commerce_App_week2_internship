## 📱 Project Overview

This project focuses on building a modern and responsive E-Commerce application using Flutter and Dart. The application includes multiple screens, interactive navigation, product and brand sections, and responsive layouts for different screen sizes.

## ✨ Features

* 🏠 Home
* 🔔 Notifications
* 👤 Account
* 💬 Messages
* ❤️ Favorites / Wishlist
* 🛒 Shopping Cart
* 🏷️ Brands
* 📦 Products
* 🗂️ Categories
* ⭐ Brand Reviews
* 🔎 Search UI
* 📱 Responsive Mobile UI
* 💻 Responsive Web UI
* 🧭 Custom Bottom Navigation
* 🔄 Brand Home, Products & Reviews navigation
